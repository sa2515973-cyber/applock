# AppLock — تطبيق قفل التطبيقات مع سجل المتطفلين

مشروع أندرويد كامل (Kotlin + Jetpack Compose) بيعمل الآتي:

- تقفل أي تطبيق تختاره برمز سري.
- لو حد جرب يفتح التطبيق وكتب رمز غلط:
  - بيصوره بالكاميرا الأمامية على طول (من غير ما يحس).
  - بيسجل الرمز اللي كتبه بالظبط + اسم التطبيق + التاريخ والوقت.
- شاشة "سجل المحاولات الفاشلة" بتعرضلك كل محاولة بصورتها ورمزها.

## ملاحظات مهمة قبل ما تستخدمه

1. **مكان الاستخدام:** الميزة دي قانونية ومنطقية لما تستخدمها على **جهازك الشخصي** عشان تحمي خصوصيتك. استخدامها على جهاز حد تاني من غير علمه بيعتبر تتبّع/تجسس وده ممنوع قانونيًا في أغلب الدول.
2. **جوجل بلاي:** تطبيقات الـ Accessibility اللي بتاخد صور بدون إذن واضح من المستخدم بتترفض من Google Play غالبًا. المشروع ده مناسب للاستخدام الشخصي (تثبيت يدوي / APK) مش للنشر على المتجر، إلا لو عدّلت الفلو عشان يبقى فيه إشعار واضح للمستخدم.
3. الرمز الحقيقي بتاعك بيتخزن مُشفّر (SHA-256) — مش نص عادي. لكن الأرقام الغلط اللي بيكتبها أي حد بتتسجل نص عادي عمدًا، عشان ده بالظبط الغرض من السجل.

## المتطلبات

- Android Studio (Koala أو أحدث)
- JDK 17
- جهاز/محاكي يشغل Android 8.0 (API 26) فأعلى

## خطوات التشغيل

1. افتح مجلد `AppLock` في Android Studio (File → Open).
2. سيب Gradle يعمل sync لأول مرة (هيحمل المكتبات تلقائيًا).
3. وصّل جهاز حقيقي (الكاميرا الأمامية والـ Accessibility بيشتغلوا أحسن على جهاز حقيقي مش محاكي).
4. اعمل Run ▶️.

## خطوات الإعداد جوه التطبيق نفسه

1. أول فتحة هتطلب منك تعمل رمز قفل (PIN) بتاعك إنت.
2. من الشاشة الرئيسية:
   - **تفعيل الصلاحيات:** هيودّيك لإعدادات Accessibility عشان تفعّل خدمة AppLock، وبعدين إذن الظهور فوق التطبيقات، وبعدين إذن الكاميرا.
   - **اختيار التطبيقات:** دوس على السويتش بجانب أي تطبيق عايز تقفله.
   - **سجل المحاولات الفاشلة:** هنا هتلاقي أي محاولة فتح غلط بصورتها.

## هيكل المشروع

```
app/src/main/java/com/example/applock/
├── MainActivity.kt                 # الشاشة الرئيسية والتنقل
├── service/LockAccessibilityService.kt   # يكتشف فتح أي تطبيق مقفول
├── ui/
│   ├── LockOverlayActivity.kt      # شاشة إدخال الرمز اللي بتظهر فوق التطبيق
│   ├── PermissionsScreen.kt
│   ├── PinSetupScreen.kt
│   ├── AppListScreen.kt            # اختيار التطبيقات المقفولة
│   └── IntruderLogScreen.kt        # عرض سجل المحاولات الفاشلة
├── data/                           # Room: Attempt, LockedApp, DAOs, Database
└── util/
    ├── PinStore.kt                 # تخزين الرمز الحقيقي مشفّر
    └── FrontCameraCapture.kt       # تصوير صامت بالكاميرا الأمامية
```

## تحديد نسخة التطبيق

الباقة الحالية اسمها `com.example.applock` — غيّرها في `app/build.gradle.kts` (`applicationId` و `namespace`) وفي `AndroidManifest.xml` لو عايز تنشره باسمك.
